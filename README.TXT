WANDERLUST - EXPLORE INDIA
HTML MINI PROJECT

PROJECT FILES

1. index.html
   Home page and navigation.

2. destinations.html
   Information about Jaipur, Manali, Goa and Udaipur.

3. travel-info.html
   Travel information and budget table.

4. travel-tips.html
   Packing lists and travel tips.

5. travel-video.html
   Embedded YouTube travel video.

6. contact.html
   Contact form with input fields.

HOW TO RUN THE PROJECT

1. Open VS Code.
2. Select File > Open Folder.
3. Open the Wanderlust project folder.
4. Open index.html.
5. Right-click and select Open with Live Server,
   if the Live Server extension is installed.
6. You can also open index.html directly in a browser.

IMPORTANT NOTES

- This project uses HTML only.
- No CSS or JavaScript is required.
- Images and video need an internet connection.
- The contact form does not send real messages.
- Travel budgets are approximate examples.
